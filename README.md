# 智控视界 —— 基于安路 EG4S20 的 HDMI 多媒体播放系统

> 2026 年全国大学生嵌入式芯片与系统设计竞赛 · 参赛作品
> 队伍：mengxin team

本项目在安路（Anlogic）EG4S20 FPGA 开发板 HX4S20 上实现一套完整的 **HDMI 多媒体播放终端**：
从 TF 卡（FAT32）读取 24 位无压缩 BMP 图片与 WAV 语音，经 SDRAM 四 bank 帧缓存后以 **640×480 HDMI**
输出，并叠加状态栏 OSD、页面层、告警提示、淡黑转场与音频波形，由板载按键 / 拨码开关完成全部交互。

![开发板](%E5%BC%80%E5%8F%91%E6%9D%BF.png)

## 一、主要功能

| 功能 | 说明 |
|---|---|
| 图片轮播 | TF 卡根目录 `PIC1~PIC4.BMP` 依次加载，四 bank 帧缓存，切页无加载等待 |
| 自适应缩放 | 读取 BMP 头实际宽高，加载时缩放到 640×480（双线性），不支持的尺寸明确拒绝并保留上一完整帧 |
| 状态栏 OSD | 顶部 20 行：页面名、源图尺寸、参数值与阈值、告警状态 |
| 页面层 OSD | 参数表面板、仪表、告警边框、滚动字幕、调节提示框 |
| 按键交互 | 翻页、自动/手动轮播、阈值调节、告警确认，短按 / 长按功能不同 |
| 转场 | 淡出到黑再放行的淡黑转场，手动翻页与自动轮播共用 |
| 告警联动 | 故障时自动切到 PIC4 并叠加热点框，全部清除后回到原页面并恢复轮播 |
| 语音提示 | `PAGE.WAV` 安全须知语音，切页提示音，告警时按节奏鸣叫（无源蜂鸣器 2.7 kHz） |
| 音频波形 | 四页底部实时波形与峰值条，与告警等级联动 |
| 画面调节 | 亮度 / 对比度多档调节，SW3 夜间模式预设 |
| 数码管 | 页面号、参数值、告警码、诊断信息轮显 |

## 三、TF 卡准备

1. 将 TF 卡格式化为 **FAT32**；
2. 把 `TF卡/` 目录下的全部文件拷贝到 **卡根目录**（不要建子目录，文件名保持大写）；
3. 文件说明：

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `PIC1.BMP` | 640×480 | 总览页（右侧 4 个图标框） |
| `PIC2.BMP` | 640×480 | 参数页（4 个面板 + 进度条槽） |
| `PIC2_1024x768.BMP` | 1024×768 | 参数页高清版，用于验证加载时自适应缩放 |
| `PIC3.BMP` | 1280×960 | 流程图页（告警热点框定位），加载时缩放到 640×480 |
| `PIC4.BMP` | 800×600 | 故障说明页，加载时缩放到 640×480 |
| `PAGE.WAV` | 48 kHz / 16 bit / 单声道 | 安全须知语音 |

图片均为 24 位无压缩 BMP。PIC1 / PIC2 为原生 640×480；PIC2_1024x768、PIC3（1280×960）、PIC4（800×600）为非原生尺寸，加载时由自适应缩放模块按 4:3 双线性缩放到 640×480，同时用于验证这条链路。

## 四、源码与工程

`src.rar` 解压后为 `src/`，用 **安路 TD（Tang Dynasty）** 打开工程：

```text
src/td_project/lab_ex5_i2s_v1.0.al
```

- 顶层模块：`top_tf_hdmi_audio.v`（模块名 `top`）
- 综合结果与 bit：`src/td_project/lab_ex5_i2s_v1.0_Runs/best_result/`
- 主要源码目录：`src/user_source/hdl_source/{SD,fb4,osd,page,fade,panel,alarm,audio,...}`

综合后通过 TD 下载 bit，即得到演示视频中的整机效果。

## 五、硬件与操作

- 主芯片：安路 **EG4S20BG256**（19,600 LUT，片上 SDRAM 2M×32bit）
- 开发板：HX4S20
- 输出：HDMI 640×480
- 时钟：`sd_card_clk` 100 MHz、`ext_mem_clk` 125 MHz、`video_clk` 25 MHz、`hdmi_5x_clk` 125 MHz

| 按键 | 短按 | 长按 |
|---|---|---|
| KEY1 | 系统复位 | — |
| KEY2 | 下一页 | 上一页 |
| KEY3 | 阈值 +1 档 | 切换调节项（SW4=0 时） |
| KEY4 | 自动 / 手动轮播切换 | 告警确认 |

- SW1 / SW2：场景切换；SW3：白天 / 夜间（夜间模式亮度对比度 ×0.75）；SW4：调节对象选择
- 蜂鸣器为无源器件，由 2.7 kHz 方波驱动
